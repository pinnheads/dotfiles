dotfiles is a set of `personal config files` that allows `me` to `set up my new machine quickly with arch and hyprland`.

## ✨ features

-   supports foo
-   can do bar
-   works with bazz

## setup

### ⚡ requirements

> arch
- networkmanager
- thunar
- btop
- sassc
- gnome-themes-extra
- gnome-tweaks
- gtk-engine-murrine
- power-profiles-daemon (enable service through systemctl)
- fuzzel
- hyprpaper
- nvidia-dkms nvidia-utils egl-wayland
- fastfetch
- hyprland hyprlock waybar dunst
- pipewire
- ripgrep
- git
- firefox
- blueman (enable bluetooth daemon through systemctl)
- cliphist
- grim slurp (screenshots)
- ddcutil

### 🚀 installation

```bash
git clone https://github.com/pinnheads/dotfiles
cd dotfiles
./stow
```
